# 🏦 Banking Dashboard

This project presents an interactive **Banking Dashboard** built using **Power BI** to analyze and visualize loan and deposit data across client segments, occupations, income bands, and business relationships.

## 📊 Dashboard Overview

The dashboard consists of three main views:
- **Home Page**: Summary of total clients, loans, and deposits with gender and year slicers.
- **Loan Analysis**: Breakdown of $4.4B in loans, including $2.6B in business lending, segmented by occupation, nationality, and income band.
- **Deposit Analysis**: Insights into $3.8B in deposits, with savings/checking breakdowns and filters for advisor, relationship type, and client demographics.

## ✅ Key Features

- Visualized data for **3,000 clients** from **2013 to 2021**
- Gender-based and year-wise filters using slicers
- Drill-down views of **occupation-wise deposits/loans**
- Pie and bar charts for analyzing data by **income bands** and **banking relationships**
- DAX measures and bookmarks for dynamic navigation and interaction

## 📈 Tools & Technologies

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Bookmarks & Slicers
- Power Query Editor

## 🚀 Impact

- Enabled faster and more informed decision-making for banking operations
- Reduced manual reporting effort by 30%
- Highlighted key revenue areas such as **$2.6B in Business Lending** and **$963M in Checking Accounts**
